DITA Wasm Validator

DTD validation of DITA topics in your browser. The DITA 1.3 DTDs were compiled ahead of time into Rust code and built to WebAssembly. Four Web Workers each run a copy of that validator, and nothing is uploaded anywhere.

STEP 1 Load a DITA project

Drop a .zip of your DITA project here. The page unpacks it in memory and keeps only the .dita topics; maps, images and other files are skipped.

Supported document types

Each topic is validated against the shell its DOCTYPE public ID names. These shells were compiled in (DITA-OT 4.2.4, DITA 1.3 and Lightweight DITA). A topic with any other DOCTYPE, such as a custom specialization, is reported as invalid.
