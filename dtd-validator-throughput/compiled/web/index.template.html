DITA Wasm Validator

DTD validation of DITA topics and maps in your browser. All 42 document-type shells of DITA 1.3, DITA 2.0 and Lightweight DITA were compiled ahead of time into Rust code and built to WebAssembly. Four Web Workers each run a copy of that validator, and your files are never uploaded.

STEP 1 Load a DITA project

Drop a .zip of your DITA project here. The page unpacks it in memory and keeps the .dita topics and .ditamap maps; images and other files are skipped.

Supported document types

Each document is validated against the shell its DOCTYPE public ID names. These shells come from DITA-OT 4.2.4, and each answers to its unversioned, versioned and 1.x/2.x public IDs (hover a name to see them). A document with any other DOCTYPE, such as a custom specialization, is reported as invalid.
