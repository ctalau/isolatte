# Podman Node v10 Baseline

A minimal script establishing the baseline container configuration required to run Node.js v10 on the constrained test environment (Linux kernel 4.4.0, 9p root filesystem). The script documents and applies the two non-default settings needed on this platform: the `vfs` storage driver (overlay and fuse-overlayfs are incompatible with 9p on kernel 4.4) configured in `/etc/containers/storage.conf`, and `cni` as the network backend (netavark and CNI bridge both fail on this kernel) configured in `/etc/containers/containers.conf`. The actual container invocation is a single `podman run --rm --network=host node:10 node --version`. This setup script served as the foundation for all subsequent container networking and sandboxing experiments in this project.
