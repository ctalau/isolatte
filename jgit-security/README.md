# JGit Security Research

Security analysis of JGit's handling of untrusted repository content, focusing on two threat vectors: (1) bare-repository escape — how symlink blobs, `objects/info/alternates`, submodule URLs, and config includes can be weaponised at the application layer even though JGit's ODB reads are themselves safe; and (2) a path-traversal proof-of-concept in JGit's Protocol V2 `want-ref` handling, where client-supplied ref names containing `../` sequences bypass `isValidRefName()` and resolve to arbitrary filesystem paths, enabling a file-existence oracle, internal git state disclosure, and server-side log injection. The `jgit-path-traversal/` subdirectory contains a self-contained Jetty/JGit test server and Python exploit scripts demonstrating both vulnerabilities.
