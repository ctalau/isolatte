# Jenkins Container Setup

A self-contained Jenkins CI environment running inside a udocker container (rootless containerisation) for testing build pipelines against local git repositories. `setup-jenkins.sh` creates two bare git repos (`repo-alpha`, `repo-beta`) on the host, pulls and configures a Jenkins image via udocker with volume mounts isolating the repos, sets up an admin user with a pre-computed bcrypt password hash and a `HudsonPrivateSecurityRealm`/`FullControlOnceLoggedInAuthorizationStrategy` security realm, generates an API token, and creates two freestyle build jobs using `file://` repo URLs. `jenkins_api_report.py` queries the Jenkins REST API to generate a structured report of jobs, builds, commit SHAs, and failure logs. `JENKINS_ENVIRONMENT.md` describes the full architecture and expected behaviour.
