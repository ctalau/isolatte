# Sandboxing

Security and sandboxing experiments collected from all unmerged branches. Every subfolder represents a distinct isolation approach explored during the project: `bwrap-seccomp` implements a hermetic bubblewrap sandbox hardened with a custom seccomp-BPF syscall filter; `nsjail-dita` wraps DITA-OT processing in an nsjail jail with namespace isolation, chroot, capability drops, CPU pinning, and a loopback-only HTTP server; `smokescreen-proxy` enforces egress ACLs on a container with no default route using Stripe's Smokescreen proxy over a veth pair; `openjdk-analysis` contains security-focused audit reports of the OpenJDK `java.lang` module covering native methods, Unsafe usage, reflection bypass, and process execution risks; `jgit-vuln-research` documents two unauthenticated path-traversal vulnerabilities in JGit's Protocol V2 parser along with a full I/O usage analysis and the responsible-disclosure email; `jenkins-container` sets up a Jenkins CI environment inside a udocker container with isolated git repos and restricted authentication; and `podman-node-v10` holds the baseline podman script that established the constrained kernel/storage environment all other container experiments built on.
