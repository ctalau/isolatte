# Bubblewrap + Seccomp-BPF Sandbox

A hermetic sandbox for running untrusted Node.js code using bubblewrap (`bwrap`) layered with a custom seccomp-BPF syscall filter. `gen_seccomp.c` compiles to a small program that emits a BPF filter (using libseccomp) which blocks ptrace, process_vm_*, perf_event_open, kexec, bpf, userfaultfd, mount/pivot/chroot, keyctl, and all inet socket families (AF_INET/AF_INET6/AF_NETLINK/AF_PACKET) as a network-namespace substitute inside Docker. `run_sandbox.sh` then launches bwrap with user-namespace isolation (uid/gid 65534), IPC/PID/UTS unsharing, all capabilities dropped, a minimal read-only filesystem, a single writable `/output` bind-mount, FD cleanup to prevent host-descriptor leaks, and the generated BPF filter applied via `--add-seccomp-fd`; `output/final_audit.txt` records the verified sandbox state confirming all caps zeroed, seccomp mode 2, and network blocked.
