# JGit Vulnerability Research

Security research into JGit's Protocol V2 implementation and I/O API surface. `jgit-java-io-report.md` maps JGit's use of `java.io` (41 classes, 1,047 files) and `java.nio` (47 classes, 235 files) across all 27 JGit modules, with deep dives on `RandomAccessFile` and file migration patterns. `jgit-want-ref-traversal.md` documents an unauthenticated path-traversal vulnerability in the Protocol V2 `fetch/want-ref` handler: client-supplied ref names containing `../` bypass `isValidRefName()` in `ProtocolV2Parser`, reach `RefDirectory.fileFor()` without sanitization, and resolve to arbitrary filesystem paths — enabling a file-existence oracle, secret commit exfiltration, server-log injection, and (on non-containerised hosts) a DoS via `/dev/tty` blocking. `jgit-vuln-email.md` is the responsible-disclosure report sent to security@eclipse.org covering both this vulnerability and a companion `ls-refs ref-prefix` branch-enumeration flaw (CVSS 7.5 each).
