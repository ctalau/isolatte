# OpenJDK java.lang Security Analysis

Four security-focused audit reports covering all 327 source files in OpenJDK 21's `java.lang` module, produced to understand what must be restricted when running untrusted Java code. The reports are split alphabetically (A–E, E–M, M–S, S–Z) and catalogue native method declarations, `Unsafe` memory operations, reflection/accessor control (`setAccessible`, `ReflectAccess`, `Proxy`), privileged actions (`AccessController.doPrivileged`), process execution risks (`Runtime.exec`, `ProcessBuilder`), `SecurityManager` integration, module system native methods (`defineModule0`, `addExports0`), virtual-thread JVMTI callbacks, Foreign Function & Memory API escape hatches, and deprecated dangerous thread operations (`stop`, `suspend`). Each entry is rated CRITICAL/HIGH/MEDIUM/LOW with sandboxing implications noted.
