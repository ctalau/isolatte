# Oxygen XML Editor User Guide PDF build with hardened bubblewrap sandbox

## Goal
Run the same Oxygen user guide workload used in the QEMU experiment, but generate **PDF** output inside the repo's hardened `bwrap + seccomp` sandbox profile.

## Workload
- input map: `DITA/UserManual.ditamap`
- ditaval profile: `DITA/ditaval/editor-sa.ditaval`
- output format: `pdf`

Sandbox runner:

```bash
bwrap-seccomp/run_oxygen_userguide_pdf_bwrap.sh
```

## Hardened sandbox profile used
The run reuses the hardening approach from `run_sandbox.sh`:
- user namespace remap (`uid/gid 65534`)
- IPC + UTS namespace isolation
- all Linux capabilities dropped (`--cap-drop ALL`)
- seccomp-BPF policy generated by `gen_seccomp.c` and applied with `--add-seccomp-fd`
- read-only binds for system paths and experiment input tree
- dedicated writable output bind mount (`/output`)
- empty environment (`--clearenv`) with minimal explicit variables
